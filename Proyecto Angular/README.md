# Pizzería - Angular

## Preparación

```powershell
npm install
npm start
```

Abre `http://localhost:4200`. La aplicación usa formularios reactivos y consume la API Flask en `http://127.0.0.1:5000`.

Inicia primero MySQL desde Laragon y después el backend Flask. Si Flask no inicia con el usuario y contraseña configurados, actualiza `MYSQL_USER` y `MYSQL_PASSWORD` en `Proyecto Flask/src/config.py`.
